# Landing-page assets

`readme-hero.svg` and `architecture.svg` are original, editable vector artwork for the repository landing page. The architecture graphic is a conceptual request-flow diagram, not a runtime trace or a screenshot. Bidirectional traffic and lifecycle details remain documented in the architecture reference.

The diagram deliberately separates the agent runtime from model inference and labels the Anthropic compatibility route as optional. It does not claim another agent runtime is implemented.

The SVGs use system-font fallbacks and fixed backgrounds, with no scripts, external fonts or remote image dependencies. Their text alternatives are also provided in the README. Assets are distributed under the repository's dual license.
